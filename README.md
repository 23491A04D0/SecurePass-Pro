# 🔐 SecurePass Pro

## Next Generation Password Security Platform

SecurePass Pro is a professional desktop password generator application built using Python and Tkinter.

The application generates strong and customizable passwords while providing security analysis, password history management, theme support, and a modern cybersecurity-inspired user interface.

---

# ✨ Features

## 🔑 Smart Password Generator

* Generate highly secure random passwords
* Customize password length
* Enable/disable:

  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Symbols

---

## 🛡 Password Security Intelligence

* Password strength evaluation
* Entropy calculation
* Crack-time estimation
* Security analysis dashboard

---

## 📚 Password History Management

* Automatically stores generated passwords
* Search previous passwords
* Manage password history locally

---

## 📋 Productivity Features

* One-click password copy
* Password visibility toggle
* Export password data
* Clear password history

---

## 🎨 Modern User Interface

* Cybersecurity-inspired dark theme
* Light/Dark theme support
* Glassmorphism card design
* Hover animations
* Professional dashboard layout
* Custom SecurePass Pro logo
* Animated startup splash screen

# 🚀 How to Run the Project

## Step 1: Download or Clone Repository

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

or download the ZIP file and extract it.

---

## Step 2: Open Project Folder

Open terminal inside:

```
SecurePass-Pro
```

Example:

```
cd SecurePass-Pro
```

---

## Step 3: Check Python Installation

Run:

```bash
python --version
```

Example output:

```
Python 3.12.0
```

---

## Step 4: Run Application

Execute:

```bash
python main.py
```
